A 4 KB Python chess engine (4,095 bytes): negamax alpha-beta with quiescence search, transposition table and a fixed 180,000-node budget. It plays UCI moves against the make.fun environment.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
